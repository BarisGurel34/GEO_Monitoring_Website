Evaluating AI Search Answers

Which businesses appear in AI search answers, and what happens to the details people rely on?

Baris Gurel

Try the claim checkFollow the study

Overview

AI search tools often combine information from several pages into one answer. A detail may change in the process. For example, an answer might leave out the minimum order for free delivery.

This study tracks how answers describe local businesses. It compares individual claims with website passages to identify which details are supported, which need more evidence, and what businesses could make clearer on their pages.

Why repeat the same question?

Ask the same question in separate sessions to see which sources and claims recur. Save the answer and the links it displays so each observation can be checked later.

When checking a claim, keep the surrounding context. A source may give a price or describe a service with a condition that changes its meaning.

What does a claim check look like?

A hypothetical example about a delivery policy.

AI answer

“The shop offers free delivery.”

Website evidence

“Free delivery on orders over $50.”

What the evidence supports

The source supports free delivery for orders over $50. The answer leaves out the minimum order value.

Suggested clarification

Place the minimum order value next to each mention of free delivery.

See how this check would be recorded
Claim
The shop offers free delivery.
Evidence
The website states that free delivery applies to orders over $50.
Assessment
Supported with a condition. The answer omits the minimum order value.

What to record

  • Visibility. Which businesses or sources appear across repeated answers?
  • Source links. Which pages are linked in the final answer? When search records are available, which other sources did the tool return?
  • Support for claims. Which details about services, fees, and locations can we check against the pages we inspect?

A separate experiment would be needed to see whether a page edit changes citations or traffic.
